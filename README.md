🧪 Testing Fundamentals – Test Case Design

Role: QA Tester
Type: QA Fundamentals
Tools: Google Sheets

🔍 Description

Project focused on test case design and requirement analysis as part of the core foundations of QA testing. The goal is to ensure software quality by identifying defects before execution through structured test design techniques.

🎯 Scope

Input validation (First Name, Last Name)

Business rules validation (distance, departure time)

Valid, invalid, and boundary data analysis

🧠 Techniques Used

Equivalence Class Partitioning

Boundary Value Analysis

Positive & Negative Scenarios

✅ Coverage

Field length limits

Empty and invalid inputs

Special and non-English characters

Out-of-range values

Time-based business rules

📈 Outcome

Designed optimized and clear test cases to detect validation and logic issues early in the development lifecycle.

💡 QA Value

Demonstrates core QA skills:

Requirement analysis

Structured test design

Early defect prevention
